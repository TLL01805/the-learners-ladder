Grammar Fix-It

Each sentence has exactly one grammar mistake. Tap the word you think is wrong, then choose the correction.

The Learners Ladder Editorial Team | 12 sentences · self-paced | Grammar Basics

Spotting an error is a different skill from knowing the rule behind it. This activity trains both — first find the mistake, then fix it correctly.

How to Use This Activity

1. Read each sentence carefully — it contains exactly one grammar mistake.
2. Tap the word you believe is incorrect.
3. Choose the correct replacement from the options shown.
4. You'll see immediate feedback and a short explanation of the rule.
5. Complete all 12 sentences, then try the quiz below.
